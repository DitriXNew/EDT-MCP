## Core

| [`get_metadata_details`](tools/get_metadata_details.md) | Inspect `objectFqns` in a project; `full=false` gives compact details and `assignable=true` discovers writable properties and allowed values. | [`get_module_structure`](tools/get_module_structure.md) | Inspect one `modulePath` for methods, regions and execution contexts. `responseFormat` defaults to concise; choose detailed for full signatures, and opt into `includeVariables` or `includeComments` (both false by default). |

| [`list_toolsets`](tools/list_toolsets.md) | Return the progressive-disclosure toolset IDs, membership and visibility as JSON, including names not currently exposed by `tools/list`. Takes no parameters; use the IDs with `enable_toolset`. |

## Debug

> Runtime debugging: launch/attach, breakpoints, step/resume/pause, variables, expression evaluation.

| Tool | Description |
|------|-------------|
| [`debug_pause`](tools/debug_pause.md) | Actively suspend a running debug session, then return its thread and stack frames. `applicationId` may be omitted only for a single active session; `timeout` defaults to 10 seconds, maximum 600. |
| [`debug_status`](tools/debug_status.md) | List active debug sessions and suspended/running state as JSON; optional `applicationId` narrows the snapshot. Use its session IDs to target pause, resume and breakpoint inspection. |
| [`evaluate_expression`](tools/evaluate_expression.md) | Evaluate required BSL `expression` in the paused frame selected by `frameRef` and return its typed value. Evaluation executes application code and can mutate state; it is not a read-only watch. |
| [`get_applications`](tools/get_applications.md) | List a project's infobase applications, IDs and update state as JSON. The response also distinguishes resolved, absent and unknown default-application resolution; use the IDs for launch/update targets. |
| [`get_variables`](tools/get_variables.md) | Inspect a paused frame using `frameRef` or `threadId` with zero-based `frameIndex` (default 0). Use dot-separated `expandPath` to drill into a nested variable; returns typed JSON values. |
| [`launch`](tools/launch.md) | Start by `launchConfigurationName` OR `projectName` plus `applicationId`; runtime clients default to debug and `updateBeforeLaunch=true`. Existing sessions return `alreadyRunning` unless `restartIfRunning=true` terminates them first; external-object startup and native TESTCLIENT/TESTMANAGER options are supported, while attach/server targets have separate update restrictions. |
| [`list_breakpoints`](tools/list_breakpoints.md) | List line-breakpoint marker IDs, conditions and hit rules, plus workspace-wide break-on-error state, as JSON. `projectName` optionally filters line breakpoints; use the IDs to update or remove them. |
| [`remove_breakpoint`](tools/remove_breakpoint.md) | Remove a breakpoint by `breakpointId`, or by `modulePath` and 1-based `lineNumber` (with project context for relative paths). `module` is a deprecated alias; a call without an identifying target is refused. |
| [`resume`](tools/resume.md) | Continue a suspended debug thread by `threadId`, or a session by `applicationId`; omitting the session ID requires a single active debug session. Returns JSON state; execution continues until another suspend event. |
| [`set_breakpoint`](tools/set_breakpoint.md) | Create/update a breakpoint at `modulePath` and 1-based `lineNumber`; relative paths need `projectName`, and `module` is deprecated. Optional `condition` and positive `hitCount` narrow stops; `hitCondition` defaults to EQUALS and hit counts require 1C 8.3.24 or newer. Registration waits for the module project context and its model. |
| [`set_error_breakpoint`](tools/set_error_breakpoint.md) | Set required `enabled` for the workspace-wide BSL exception breakpoint. Omit `exceptionMessage` to keep its filter, pass an empty string to catch all, or supply a message template; disabling preserves the filter. |
| [`set_variable`](tools/set_variable.md) | Set required `variableName` to BSL `value` in a paused `frameRef`, or `threadId` with zero-based `frameIndex` (default 0); dotted variable paths reach nested members. The value is evaluated as code and can change state beyond that variable. |
| [`step`](tools/step.md) | Advance suspended `threadId` using required `kind=over`, into or out. Wait up to `timeout` (default 30 seconds) and return the resulting stack snapshot. |
| [`terminate_launch`](tools/terminate_launch.md) | Stop a named launch, or `projectName` plus `applicationId`, immediately; only `all=true` requires `confirm=true`. `timeout` defaults to 10 seconds, `force=false` avoids OS-kill escalation, and `includeAttach=true` disconnects attach sessions without stopping their server. |
| [`wait_for_break`](tools/wait_for_break.md) | Wait for a suspend event and return `threadId`, stable `frameRef` values and stack frames; it does not request a pause. `timeout` defaults to 60 seconds; `applicationId` is optional only when one debug session is active. |
